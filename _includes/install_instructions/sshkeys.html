SSH Token Setup

This is VERY important to do before the workshop in order to complete the Git workshop. This information can also be found here


Note for Windows Users

  • If you have used Windows Subsystem for Linux ("WSL2") please open your Ubuntu bash terminal to enter the commands
  • If not, please use the git-bash.

  1. Open up your terminal (“git-bash” for Windows or “terminal” for Mac and Linux)

  2. To create an SSH key pair use this command, where the `-t` option specifies which type of algorithm to use:

    3. $ ssh-keygen -t ed25519

  3. The command will ask for a file name, press Enter to use the default

    4. Generating public/private ed25519 key pair. Enter file in which to save the key (/c/Users/Alfredo/.ssh/id_ed25519):

  4. You’ll be prompted for a passphrase, be sure to pick something memorable as there’s no “reset my password” option. You’ll also note you won’t see any of the letters/numbers/symbols you type, this is all normal and what you type is recorded even if they don’t show up

    5. Created directory '/c/Users/Alfredo/.ssh'. Enter passphrase (empty for no passphrase):

  5. You’ll be prompted to enter the passphrase again, enter the same passphrase you entered in step 3

    6. Enter same passphrase again:

  6. After entering the passphrase, you will see something like below. (note the specific output will be different for your system, that is normal). This means the ssh key is created.

    7. Your identification has been saved in /c/Users/Alfredo/.ssh/id_ed25519
    Your public key has been saved in /c/Users/Alfredo/.ssh/id_ed25519.pub
    The key fingerprint is:
    SHA256:SMSPIStNyA00KPxuYu94KpZgRAYjgt9g4BA4kFy3g1o a.linguini@ratatouille.fr
    The key's randomart image is:
    +--[ED25519 256]--+
    |^B== o. |
    |%*=.*.+ |
    |+=.E =.+ |
    | .=.+.o.. |
    |.... . S |
    |.+ o |
    |+ = |
    |.o.o |
    |oo+. |
    +----[SHA256]-----+

  7. Run the below command

    8. $ cat ~/.ssh/id_ed25519.pub

  8. Copy what is output to the command line, it should look like the below:

    9. ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIDmRA3d51X0uu9wXek559gfn6UFNF69yZjChyBIU2qKI

  9. Go to github.com and login to your account

  10. Click on the profile icon in the top right corner to access the drop down menu

  11. Click “Settings”

  12. Click “SSH and GPG Keys” on the left side, with the “Access” menu

  13. Click the “New SSH Key” button

  14. Enter a name for the SSH Key (something easy to remember)

  15. Paste your key you copied from step 7 into the large text box

  16. Click “Add SSH key” to complete setup

  17. Go back to the command line, and run this command

    18. $ ssh -T git@github.com

  18. You should receive output like the below, indicating it a success!

    19. Hi Alfredo! You've successfully authenticated, but GitHub does not provide shell access.
